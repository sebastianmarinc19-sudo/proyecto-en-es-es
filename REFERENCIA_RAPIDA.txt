🎯 OBJETIVO: Reconocimiento de Actividad Humana mediante Teléfonos Inteligentes

================================================================================
                           CONFIGURACIÓN INICIAL
================================================================================

1. CREAR AMBIENTE VIRTUAL (si no existe):
   python -m venv .venv

2. ACTIVAR AMBIENTE:
   .venv\Scripts\Activate.ps1
   (Debes ver (.venv) al inicio de la terminal)

3. INSTALAR LIBRERÍAS:
   pip install -r requirements.txt

4. VERIFICAR TODO:
   python scripts/00_inicio.py

================================================================================
                            SCRIPTS PRINCIPALES
================================================================================

00_inicio.py
   ├─ Verifica que librerías estén instaladas
   ├─ Comando: python scripts/00_inicio.py
   └─ Salida: Lista de versiones ✓

01_exploracion.py (PRÓXIMO PASO)
   ├─ Análisis Exploratorio de Datos (EDA)
   ├─ Comando: python scripts/01_exploracion.py
   └─ Salida: Gráficos en results/graficos/

02_entrenamiento.py
   ├─ Preprocesa datos y entrena modelos
   ├─ Comando: python scripts/02_entrenamiento.py
   └─ Salida: Modelos en results/modelos/

03_evaluacion.py
   ├─ Evalúa todos los modelos
   ├─ Comando: python scripts/03_evaluacion.py
   └─ Salida: Métricas en results/metricas.csv

================================================================================
                        SOLUCIONES RÁPIDAS
================================================================================

PROBLEMA: "python no encontrado"
→ Reinstala Python, marca "Add Python to PATH"

PROBLEMA: "ModuleNotFoundError"
→ Activa ambiente: .venv\Scripts\Activate.ps1

PROBLEMA: ".venv no se activa"
→ Ejecuta: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

PROBLEMA: "pip no reconocido"
→ Python no está en PATH, reinstala

PROBLEMA: "No se genera gráficos"
→ Verifica que plt.show() está en el script
